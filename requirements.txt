# ============================================================
# Notes
# ============================================================
#
# 1. MySQL:
#    Development can use asyncmy with SQLAlchemy AsyncEngine.
#    PyMySQL is retained for compatibility / synchronous scripts.
#
# 2. Qdrant:
#    qdrant-client is the only required Python SDK.
#    Qdrant itself should run as an external services / Docker
#    container rather than being installed through pip.
#
# 3. LLM:
#    openai provides an OpenAI-compatible client.
#    It can be used with OpenAI-compatible providers such as
#    DeepSeek and other compatible APIs by changing the base_url.
#
# 4. Embedding:
#    sentence-transformers supports local embedding models.
#    If Ollama is used for embeddings, communication can be
#    implemented through HTTP using httpx/aiohttp.
#
# 5. Workflow:
#    No LangGraph dependency is intentionally included.
#    Workflow Engine is self-developed in app/workflow/.
#
# 6. Multi-Agent:
#    No heavyweight Agent framework is required initially.
#    Agent orchestration is implemented in app/agents/.
#
# 7. Skill:
#    External Skills are integrated through an adapter layer.
#    Core project-analysis Skills are implemented in
#    app/skills/.
#
# 8. Frontend:
#    No React / frontend dependency is included at this stage.
#
# 9. Redis / Celery:
#    Included for the later long-running task / worker phase.
#    They are NOT required for the first local MVP.
#
# 10. Docker:
#    Docker itself is installed outside Python requirements.
#
